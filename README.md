
# Book Reading List Application

## Project Overview
BookNest is an interactive web application that helps users organize their personal reading lists. Users can add books, track their reading status, search for titles or authors, and remove books when needed.

## Objectives
- Build a practical application using HTML, CSS, and JavaScript.
- Practise DOM manipulation, event handling, arrays, and functions.
- Track reading progress through different book statuses.
- Create a simple, responsive interface.

## Features
- Add a book title and optional author name.
- Choose a reading status: Want to Read, Currently Reading, or Completed.
- Prevent empty and duplicate book titles.
- Search books by title or author.
- Filter books by reading status.
- Change a book's status at any time.
- Delete books from the list.
- Display total, unread, currently reading, and completed book counts.
- Responsive design for desktop and mobile devices.
- Limit the list to 100 books.

## Technologies Used
- **HTML5:** Structure of the application.
- **CSS3:** Styling and responsive layout.
- **JavaScript:** Book management, search, filters, validation, and summary counts.

## Project Files
- `index.html` — application structure.
- `style.css` — styling and responsive design.
- `script.js` — application functionality.

## How to Run
1. Download or clone this repository.
2. Keep all three application files in the same folder.
3. Open `index.html` in a web browser.
4. Enter a book title and optionally an author.
5. Select a reading status and click **Add Book**.
6. Use the search box and status filter to find books.
7. Update a book's status or delete it when needed.

## Important Note
This version stores books in memory only. The list resets when the page is refreshed. Permanent browser storage can be added as a future enhancement.
